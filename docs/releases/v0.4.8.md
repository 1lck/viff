### 重点更新

每个窗口拥有自己的活动仓库、编辑页签、提交草稿和终端，已添加的仓库列表和偏好设置在窗口间共享。

#### ✨ 新功能

- 从左上角项目菜单选择「在新窗口中打开…」，在保留当前窗口的同时打开另一个本地仓库。

#### ⚡ 改进

- 退出应用或确认重启安装更新时，Viff 会检查所有窗口是否有未保存的编辑。

### 升级说明

- macOS：按机型选择 Apple Silicon 或 Intel 的 DMG，退出旧版后打开 DMG，将 Viff.app 拖入“应用程序”并替换旧版。
- Windows：退出旧版后运行 x64 安装器。
- Windows 便携包：解压后进入新目录执行 `viff.exe`，不写入安装信息。
- Debian/Ubuntu：执行 `sudo apt install ./viff-v0.4.8-linux-amd64.deb`。
- Linux 便携包：解压后进入新目录执行 `./viff`，并自行安装所需系统库。
- Git 需单独安装并加入 `PATH`，Linux 系统库要求见[发布指南](https://github.com/1lck/viff/blob/v0.4.8/docs/releases.md)。

### 兼容性与已知问题

- macOS 要求 13 或更高版本。Linux 需要可用的图形会话、渲染后端和发布指南中列出的系统库。
- macOS 应用使用 ad-hoc 签名，未取得 Developer ID 签名和公证。Windows 安装器未取得 Authenticode 签名。系统可能显示安全提示。
- 应用重启时恢复一个窗口。

仅安装来自项目发布页且已核对校验值的文件。

### Highlights

Each window has its own active repository, editor tabs, commit drafts, and terminal, while the repository list and preferences are shared across windows.

#### ✨ New features

- Choose Open in New Window… from the project menu in the upper-left corner to open another local repository while keeping the current window open.

#### ⚡ Improvements

- Viff checks every window for unsaved edits when you quit the app or confirm a restart to install an update.

### Upgrade instructions

- macOS: choose the Apple Silicon or Intel DMG, quit the old version, open the DMG, and replace Viff.app in Applications.
- Windows: quit the old version and run the x64 installer.
- Windows portable: extract the archive, enter its directory, and run `viff.exe` without installing.
- Debian/Ubuntu: run `sudo apt install ./viff-v0.4.8-linux-amd64.deb`.
- Linux portable: extract the archive, enter its directory, and run `./viff` after installing the required system libraries.
- Install Git separately on `PATH`, and check the [release guide](https://github.com/1lck/viff/blob/v0.4.8/docs/releases.md) for Linux dependencies.

### Compatibility and known issues

- macOS requires version 13 or later. Linux needs a working graphical session, rendering backend, and the libraries listed in the release guide.
- The macOS app uses ad-hoc signing and has no Developer ID signature or notarization. The Windows installer has no Authenticode signature. The operating system may show a security prompt.
- Viff restores one window when it restarts.

Install packages from the project release page after checking their checksums.
