### 重点更新

本次的核心是应用内更新，以及为它补齐的 Windows 便携 ZIP。Viff 仍然是一个原生 Go 程序，不捆绑 Electron 或浏览器运行时。

#### ✨ 新功能

- 应用内更新：启动时静默检查（可在设置关闭）或从“Check for Updates…”手动检查，发现新版本后显示版本与发布说明。
- 应用内下载：下载过程显示进度并支持取消，完成后用发布页的 `SHA256SUMS` 校验，校验失败不会安装。
- 重启以更新：点“Restart to Update”后 Viff 退出，helper 在后台替换当前安装并自动启动新版本；macOS 替换整个应用包，Windows 与 Linux 便携包替换可执行文件。
- Windows：新增便携 ZIP，既可作为免安装版本使用，也是应用内更新在 Windows 上的下载包。
- Linux：便携包继续自替换；DEB 安装会下载对应的 DEB，并提示用 `sudo apt install` 完成提权安装，不直接改写包管理器管理的文件。
- 设置：新增“Check for updates at startup”开关，默认开启。

### 升级说明

- 从 v0.1.0 或更早版本升级：本版是第一个带更新器的版本，需要先手动安装一次；之后的新版本可以在应用内升级。
- macOS：按机型选择 Apple Silicon 或 Intel 的 DMG，退出旧版后打开 DMG，将 Viff.app 拖入“应用程序”并替换旧版。
- Windows：退出旧版后运行 x64 安装器；也可以解压便携 ZIP 后运行 `viff.exe`。
- Debian/Ubuntu：执行 `sudo apt install ./viff-v0.1.1-linux-amd64.deb`。
- Linux 便携包：解压后进入新目录执行 `./viff`，并自行安装所需系统库。
- Git 需单独安装并加入 `PATH`，Linux 系统库要求见[发布指南](https://github.com/1lck/viff/blob/v0.1.1/docs/releases.md)。

### 兼容性与已知问题

- macOS 包要求 macOS 13 及以上，Apple Silicon 与 Intel 机型均可安装。
- macOS 应用使用 ad-hoc 签名，尚无 Developer ID 签名或公证；Windows 安装器尚无 Authenticode 签名，系统可能显示安全提示。
- 应用内更新使用 HTTPS 与 SHA-256 校验，不做系统签名校验；下载来源是本项目 GitHub Releases。
- Windows 与 Linux 的自替换只更新可执行文件，随包文档和 Windows 卸载项中的版本号保持旧值，直到下次完整安装；macOS 替换整个应用包。
- DEB 安装受权限限制，最后一步需要 `sudo apt install`，无法完全一键完成。
- 更新检查是 Viff 默认开启的唯一网络请求，只读取公开版本信息；可在设置关闭，详见[隐私说明](https://github.com/1lck/viff/blob/v0.1.1/docs/privacy.md)。
- 输入法、外部编辑器与各类显卡环境仍需在实际桌面环境继续验收。

仅安装来自本项目发布页且已核对校验值的文件；若系统拦截，请先确认来源，再使用系统提供的允许打开选项。

## English

Viff 0.1.1 adds in-app updates. Viff checks at startup or from the Help menu, downloads the package inside the app, verifies it with SHA-256, and replaces and relaunches itself through “Restart to Update” without opening a browser. Windows also gains a portable ZIP, and later releases can upgrade from inside the app.

### Highlights

The core of this release is the in-app updater, together with the Windows portable ZIP it needs. Viff remains a native Go application without Electron or a bundled browser runtime.

#### ✨ New features

- In-app updates: Viff checks quietly at startup (configurable in Settings) or on demand from “Check for Updates…”, then shows the version and release notes.
- In-app download: progress and cancellation, followed by a SHA-256 check against the release’s `SHA256SUMS`; a mismatch is never installed.
- Restart to update: “Restart to Update” quits Viff, a helper replaces the current installation, and the new version starts automatically. macOS replaces the whole application bundle; Windows and the Linux portable archive replace the executable.
- Windows: a portable ZIP that doubles as the download package for in-app updates and as a no-install option.
- Linux: the portable archive still updates itself; a DEB installation downloads the matching DEB and asks for `sudo apt install` instead of overwriting files owned by the package manager.
- Settings: a “Check for updates at startup” switch, enabled by default.

### Upgrade instructions

- Upgrading from v0.1.0 or earlier: this is the first release with the updater, so install it by hand once; later releases can upgrade from inside the app.
- macOS: choose the Apple Silicon or Intel DMG, quit the old version, open the DMG, and replace Viff.app in Applications.
- Windows: quit the old version and run the x64 installer, or extract the portable ZIP and run `viff.exe`.
- Debian/Ubuntu: run `sudo apt install ./viff-v0.1.1-linux-amd64.deb`.
- Linux portable: extract the archive, enter its directory, and run `./viff` after installing the required system libraries.
- Install Git separately on `PATH`, and check the [release guide](https://github.com/1lck/viff/blob/v0.1.1/docs/releases.md) for Linux dependencies.

### Compatibility and known issues

- The macOS package requires macOS 13 or later and runs on both Apple Silicon and Intel Macs.
- The macOS app is ad-hoc signed without Developer ID signing or notarization, and the Windows installer is not Authenticode signed, so the operating system may show a security prompt.
- In-app updates use HTTPS and SHA-256, not operating-system signature verification; downloads come from this project’s GitHub Releases.
- Windows and Linux self-updates replace only the executable, so bundled documentation and the Windows uninstall entry keep the old version until a full install; macOS replaces the whole bundle.
- A DEB installation needs `sudo apt install` as its final step, so it cannot be fully automatic.
- The update check is Viff’s only default network request and only reads public release metadata; it can be disabled in Settings. See the [privacy guide](https://github.com/1lck/viff/blob/v0.1.1/docs/privacy.md).
- Input methods, external editors, and graphics configurations still need acceptance on real desktops.

Install only files from this project's release page after checking their checksums; if blocked, verify the source before using the operating system's option to allow the app.
