### 重点更新

本次从预发布转为正式版，保持 Go 与 Viva 的轻量原生形态，不捆绑 Electron 或浏览器运行时；集中修复 Windows 使用体验，补齐 Intel Mac 安装包，并增强问题排查能力。

#### ✨ 新功能

- macOS：新增 Intel 机型安装包，Apple Silicon 与 Intel 可分别下载对应的 DMG。
- 帮助菜单：新增“Report a Problem…”录制入口与诊断包导出，便于把问题整理成可分享的排查材料。
- 稳定性：新增本地崩溃记录，异常退出后再次启动会给出提示并支持导出。

#### ⚡ 改进

- 品牌：应用图标统一为白底橙色图标，Windows 安装器与开始菜单同步更新。
- Windows：Git 命令在后台静默执行，不再打断当前操作。

#### 🛠 修复

- Windows：修复打开应用后控制台黑框连续闪现、界面无法操作的问题。

### 升级说明

- macOS：按机型选择 Apple Silicon 或 Intel 的 DMG，退出旧版后打开 DMG，将 Viff.app 拖入“应用程序”并替换旧版。
- Windows：退出旧版后运行 x64 安装器，原 ZIP 解压目录可在确认迁移后删除。
- Debian/Ubuntu：执行 `sudo apt install ./viff-v0.1.0-linux-amd64.deb`。
- Linux 便携包：解压后进入新目录执行 `./viff`，并自行安装所需系统库。
- Git 需单独安装并加入 `PATH`，Linux 系统库要求见[发布指南](https://github.com/1lck/viff/blob/v0.1.0/docs/releases.md)。

### 兼容性与已知问题

- macOS 包要求 macOS 13 及以上，Apple Silicon 与 Intel 机型均可安装。
- macOS 应用使用 ad-hoc 签名，尚无 Developer ID 签名或公证，首次打开可能需要在系统设置中允许。
- Windows x64 安装器尚无 Authenticode 签名，系统可能显示安全提示。
- Linux x64 的 DEB 适用于 Debian/Ubuntu，其他发行版需自行满足便携包依赖。
- 本次未提供 Homebrew 安装方式或自动更新。
- 输入法、外部编辑器与各类显卡环境仍需在实际桌面环境继续验收。

仅安装来自本项目发布页且已核对校验值的文件；若系统拦截，请先确认来源，再使用系统提供的允许打开选项。

### Highlights

This is the first stable release. Viff keeps its lightweight native form built with Go and Viva, without Electron or a bundled browser runtime. It focuses on the Windows experience, adds an Intel Mac package, and improves troubleshooting.

#### ✨ New features

- macOS: install the DMG that matches your Mac, with separate Apple Silicon and Intel packages.
- Help menu: record a problem with “Report a Problem…” and export a diagnostic bundle to share.
- Stability: local crash reports appear on the next launch after an abnormal exit and can be exported.

#### ⚡ Improvements

- Branding: the application icon is now the orange-on-white Viff mark on every platform, including the Windows installer and Start menu.
- Windows: Git commands run silently in the background instead of interrupting your work.

#### 🛠 Fixes

- Windows: fix console windows flashing repeatedly after launch and making the application unusable.

### Upgrade instructions

- macOS: choose the Apple Silicon or Intel DMG, quit the old version, open the DMG, and replace Viff.app in Applications.
- Windows: quit the old version and run the x64 installer before removing any obsolete ZIP extraction directory.
- Debian/Ubuntu: run `sudo apt install ./viff-v0.1.0-linux-amd64.deb`.
- Linux portable: extract the archive, enter its directory, and run `./viff` after installing the required system libraries.
- Install Git separately on `PATH`, and check the [release guide](https://github.com/1lck/viff/blob/v0.1.0/docs/releases.md) for Linux dependencies.

### Compatibility and known issues

- The macOS package requires macOS 13 or later and runs on both Apple Silicon and Intel Macs.
- The macOS app is ad-hoc signed, without Developer ID signing or notarization, so the first launch may require approval in System Settings.
- The Windows x64 installer is not Authenticode signed, so Windows may show a security warning.
- The Linux x64 DEB targets Debian/Ubuntu, while other distributions must provide the portable archive's dependencies.
- This release does not provide Homebrew installation or automatic updates.
- Input methods, external editors, and graphics configurations still need further acceptance on real desktops.

Install only files from this project's release page after checking their checksums; if blocked, verify the source before using the operating system's option to allow the app.
