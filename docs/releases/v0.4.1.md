### 重点更新

这一版减少启动和后台刷新的等待，同时让分支双击行为可配置。

#### ✨ 新功能

- 分支双击默认只筛选日志；可在设置中启用双击检出，右键检出仍然可用。

#### ⚡ 改进

- 减少启动时对远程仓库路径和版本探测的等待，并降低部分平台的后台刷新频率。
- 文件管理器菜单按系统显示 Finder、文件资源管理器或文件管理器。

#### 🛠 修复

- 对话框打开时暂时隐藏通知气泡，关闭后恢复显示，避免遮挡按钮。
- 历史读取结束后及时释放进程，减少仓库文件被占用的情况。

### 升级说明

- macOS：按机型选择 Apple Silicon 或 Intel 的 DMG，退出旧版后打开 DMG，将 Viff.app 拖入“应用程序”并替换旧版。
- Windows：退出旧版后运行 x64 安装器。
- Windows 便携包：解压后进入新目录执行 `viff.exe`，不写入安装信息。
- Debian/Ubuntu：执行 `sudo apt install ./viff-v0.4.1-linux-amd64.deb`。
- Linux 便携包：解压后进入新目录执行 `./viff`，并自行安装所需系统库。
- Git 需单独安装并加入 `PATH`，Linux 系统库要求见[发布指南](https://github.com/1lck/viff/blob/v0.4.1/docs/releases.md)。

### 兼容性与已知问题

- macOS 要求 13 或更高版本；Linux 需要可用的图形会话、渲染后端和发布指南中列出的系统库。
- macOS 应用使用 ad-hoc 签名，未经 Developer ID 签名或公证；Windows 安装器未经 Authenticode 签名，系统可能显示安全提示。
- Windows 和 Linux 上外部工作区文件变化可能需要最多约 30 秒才会刷新；WSL 仓库使用独立的轮询间隔。
- Subversion 属性编辑和锁操作尚未实现；WSL 仓库的内置终端与内容搜索仍在 Windows 侧运行。

仅安装来自项目发布页且已核对校验值的文件；如遇系统拦截，请先确认来源。

### Highlights

This release reduces startup and background refresh waits and makes branch double-click behavior configurable.

#### ✨ New features

- Double-clicking a branch filters the log by default; enable checkout on double-click in settings, or use the context menu to check out.

#### ⚡ Improvements

- Reduce startup waits for remote repository paths and version probes, and refresh less often in the background on some platforms.
- Name the file manager action Finder, File Explorer, or File Manager for the current system.

#### 🛠 Fixes

- Hide notification balloons while a dialog is open and show them again after it closes, so they do not cover buttons.
- Release the history reader process when reading finishes, reducing files held open in the repository.

### Upgrade instructions

- macOS: choose the Apple Silicon or Intel DMG, quit the old version, open the DMG, and replace Viff.app in Applications.
- Windows: quit the old version and run the x64 installer.
- Windows portable: extract the archive, enter its directory, and run `viff.exe` without installing.
- Debian/Ubuntu: run `sudo apt install ./viff-v0.4.1-linux-amd64.deb`.
- Linux portable: extract the archive, enter its directory, and run `./viff` after installing the required system libraries.
- Install Git separately on `PATH`, and check the [release guide](https://github.com/1lck/viff/blob/v0.4.1/docs/releases.md) for Linux dependencies.

### Compatibility and known issues

- macOS requires version 13 or later; Linux needs a working graphical session, rendering backend, and the system libraries listed in the release guide.
- The macOS app is ad-hoc signed without Developer ID signing or notarization; the Windows installer is not Authenticode signed, so the system may show a security prompt.
- On Windows and Linux, external working-tree file changes may take up to about 30 seconds to refresh; WSL repositories use a separate polling interval.
- Subversion property editing and locking are not implemented; the integrated terminal and content search for WSL repositories still run on Windows.

Install only files from the project release page after checking their checksums; verify the source if the operating system blocks them.
