### 重点更新

本次集中完善安装与分发，保留现有 Git 工作流，不捆绑 Electron 或浏览器运行时。

#### ✨ 新功能

- macOS：提供 DMG，可将 Viff 拖入“应用程序”。
- Windows：提供当前用户安装器，附带开始菜单快捷方式和卸载入口。
- Linux：提供 DEB 安装包和解压即用的便携包。

#### ⚡ 改进

- Windows：启动应用时不再附带控制台窗口。

### 升级说明

- macOS：退出旧版后打开 DMG，将 Viff.app 拖入“应用程序”并替换旧版。
- Windows：退出旧版后运行 x64 安装器，原 ZIP 解压目录可在确认迁移后删除。
- Debian/Ubuntu：执行 `sudo apt install ./viff-v0.1.0-alpha.2-linux-amd64.deb`。
- Linux 便携包：解压后进入新目录执行 `./viff`，并自行安装所需系统库。
- Git 需单独安装并加入 `PATH`，Linux 系统库要求见[发布指南](https://github.com/1lck/viff/blob/v0.1.0-alpha.2/docs/releases.md)。

### 兼容性与已知问题

- macOS 包面向 macOS 13 及以上的 Apple Silicon 设备，暂不提供 Intel 包。
- macOS 应用使用 ad-hoc 签名，尚无 Developer ID 签名或公证。
- Windows x64 安装器尚无 Authenticode 签名，系统可能显示安全提示。
- Linux x64 的 DEB 适用于 Debian/Ubuntu，其他发行版需自行满足便携包依赖。
- 当前仍是预发布版本，完整桌面交互、输入法和各类显卡环境仍需进一步验收。
- 本次未提供 Homebrew 安装方式或自动更新。

仅安装来自本项目发布页且已核对校验值的文件；若系统拦截，请先确认来源，再使用系统提供的允许打开选项。

### Highlights

This release improves installation and distribution while preserving existing Git workflows, without bundling Electron or a browser runtime.

#### ✨ New features

- macOS: install Viff by dragging the app from its DMG into Applications.
- Windows: install for the current user with a Start menu shortcut and an uninstall entry.
- Linux: choose a DEB installer or an archive you can extract and run.

#### ⚡ Improvements

- Windows: launching Viff no longer opens an accompanying console window.

### Upgrade instructions

- macOS: quit the old version, open the DMG, and replace Viff.app in Applications.
- Windows: quit the old version and run the x64 installer before removing any obsolete ZIP extraction directory.
- Debian/Ubuntu: run `sudo apt install ./viff-v0.1.0-alpha.2-linux-amd64.deb`.
- Linux portable: extract the archive, enter its directory, and run `./viff` after installing the required system libraries.
- Install Git separately on `PATH`, and check the [release guide](https://github.com/1lck/viff/blob/v0.1.0-alpha.2/docs/releases.md) for Linux dependencies.

### Compatibility and known issues

- The macOS package requires macOS 13 or later on Apple Silicon, with no Intel package available yet.
- The macOS app is ad-hoc signed, without Developer ID signing or notarization.
- The Windows x64 installer is not Authenticode signed, so Windows may show a security warning.
- The Linux x64 DEB targets Debian/Ubuntu, while other distributions must provide the portable archive's dependencies.
- This remains a pre-release, with further acceptance needed for desktop interaction, input methods, and graphics configurations.
- This release does not provide Homebrew installation or automatic updates.

Install only files from this project's release page after checking their checksums; if blocked, verify the source before using the operating system's option to allow the app.
