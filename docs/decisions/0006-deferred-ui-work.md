# 0006 绘制期间产生的延迟工作

- 状态：已采用（2026-11）

## 背景
Viva 的 `Canvas.AfterPaint` 只在点击的事件轮次中执行，普通绘制中排入的函数会被静默丢弃。凡是在普通绘制中触发的工作都会因此失效，例如懒加载 stash 文件、日志搜索的 400ms 防抖、通知气泡自动隐藏、焦点移交等。

## 决定
`Window.after` 把函数排入窗口自己的队列。绘制结束时，若队列非空，就同时注册 `AfterPaint`（覆盖点击轮次）并调用 `Invalidate`；对应的 `OnWake` 会执行队列。两条路径中先到的一条执行，队列随即清空，所以每个函数只运行一次。在事件处理函数（绘制之外）中调用时，直接唤醒。

无界面测试 `assertIdle` 会检查空闲时窗口不再重绘，用来防止因条件没有及时清除而形成的重绘循环。

## 代价
在普通绘制中排入的工作要多一次唤醒与重绘。

## 复审条件
Viva 提供“在任意绘制之后执行”的接口时改用该接口。
