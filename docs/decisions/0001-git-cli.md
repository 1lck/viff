# 0001 通过 Git 命令行访问仓库

- 状态：已采用（2026-11）

## 背景
设计要求 Git 状态正确优先，覆盖 worktree、未合并索引、钩子、凭据助手、子模块等真实场景。

## 替代项
- go-git 等纯 Go 实现：无需外部进程，但钩子、凭据助手、部分合并与 rebase 行为与官方 Git 不一致。
- libgit2 绑定：需要 cgo 与额外原生依赖，行为同样存在差异。

## 决定
`internal/gitcli` 调用用户的 `git` 可执行文件，只使用机器可读格式（`status --porcelain=v2 -z`、`--name-status -z`、`for-each-ref --format`、NUL 分隔的 `log`）。每个工作区的写操作串行执行，并记录到 Console 页签。

## 代价
- 依赖本机 Git（设置里可指定路径）。
- 每次操作都要启动进程；通过合并刷新和批量命令控制次数。

## 复审条件
需要在没有 Git 的环境运行，或进程开销成为可测量的瓶颈时。
