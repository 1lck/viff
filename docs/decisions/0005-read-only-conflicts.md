# 0005 只读冲突查看器

- 状态：部分被 [0019](0019-git-issue-gaps.md) 替代（2026-11），被 [0051](0051-editable-conflict-result.md) 替代（2026-11）；以下保留原决策背景。

## 背景
设计稿把冲突处理定为只读体验：Viff 负责展示和校验冲突，编辑交给用户的编辑器。

## 决定
- 冲突文件依据未合并索引（stage 1/2/3）和仓库的操作状态判定，而不是靠搜索 `<<<<<<<`。
- 查看器分三栏：Ours（HEAD）、Result（磁盘上的文件）、Theirs（被合并的提交），可在冲突块之间跳转。磁盘上的文件变化后会自动重新加载。
- 只有当文件中不再有冲突标记时，“Mark as Resolved”才可用，点击后暂存该文件。非文本冲突（删除对修改等）可以直接标记解决。
- “Open in Editor”定位到当前冲突块所在的行。

## 代价
不能像 IDEA 那样在应用内逐块接受左右两侧的修改。

## 复审条件
用户需要在应用内合并时，引入可编辑的结果栏。
